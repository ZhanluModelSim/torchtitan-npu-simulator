## 11. 缩放策略总结

| 维度类别 | 100T vs 50T | 策略 |
|---------|:----------:|------|
| 宽度 / 深度 / 头数 | 1.00× | 完全不变 |
| routed_experts | **2.00×** | **唯一扩参轴** |
| seq_len | **2.00×** | 上下文翻倍 |
| CSA 压缩比 | 1.50× | 平衡全局 KV |
| HCA 压缩比 | 2.00× | **comp_len 恒定** |
| KDA state / d_k | 2.00× | 线性注意力容量翻倍 |
| topk | 1.00× | 4096 恒定，稀疏度恒定 |
| Engram 层数 | 2.00× | 与参数翻倍同步 |
| yarn_factor | 2.00× | 支持更长上下文外推 |
| num_recursion | 1.00× | 5 轮 cycle 不变 |

**核心设计原则：**
1. **100T 仅通过 routed_experts 翻倍 + KDA state 翻倍实现参数翻倍**
2. **HCA 压缩比随 seq_len 翻倍**，comp_len 恒定 65536
3. **KDA 线性注意力无 KV cache**，是 13,000× 压缩的核心贡献者
4. **MoR cycle 复用 5×**，KV cache 仅存 base_depth=12 层
5. **Engram 严格 10%**，与扩参同步翻倍
6. **LatentMoE moe_latent_dim=7168** 是质量提升关键，单专家 +104% 参数
